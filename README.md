# 래서판다 빌리지

여러 방문자가 하나의 레서판다 마을에 접속해 산책하고 채팅하며, 장소에 남은 작은 흔적을 이어가는 웹 cozy game입니다.

**[▶ 지금 플레이하기](https://lessor-panda-village.vercel.app)** · 설치 없이 브라우저에서 바로 실행됩니다.

## 무엇을 할 수 있나요

- 걷기·달리기·점프·클릭 이동, 인사/춤 이모트, 벤치 앉기
- 대나무 숲에서 죽순 수확 (30초 리스폰)
- 마을 게시판에 죽순으로 방명록을 걸고, 다시 와서 확인
- 하나의 전역 월드에서 다른 방문자와 실시간으로 위치·상태·채팅 공유
- 2분 주기 낮/밤 전환 — 접속 시각과 무관하게 모든 클라이언트가 같은 시간대를 공유

계정 가입이 없습니다. Supabase 익명 로그인으로 정체성을 만들고, 닉네임과 흔적은 서버에 영속됩니다.

## 기술적으로 풀어낸 문제

포트폴리오로서 봐주셨으면 하는 부분입니다. 전부 실측값이며, 재현 방법은 각 항목의 코드 경로에 주석으로 남겨 두었습니다.

### 1. 60fps를 위한 렌더 루프 정리

브라우저에서 도는 3D 월드라 프레임 예산이 곧 제품 품질입니다. 프로파일링으로 찾은 낭비를 걷어냈습니다.

| 항목 | 개선 전 | 개선 후 |
|---|---|---|
| 집 / 고목 삼각형 | 885,380 / 349,791 | **46,067 / 22,127** |
| `public/models` 용량 | 9.1MB | **3.2MB** |
| 정적 인스턴스 행렬 갱신 | 매 프레임 약 2,700개 | **리렌더 직후 1프레임** |
| 그림자맵 | 매 프레임 재생성 | **캐스터가 움직인 프레임만** |
| 후처리 MSAA | 8× (약 300MB 렌더 타깃) | **4×** |

- **에셋 압축은 용량이 아니라 렌더 비용이 목적입니다.** 다운로드 크기를 85% 줄여도 GPU가 처리하는 삼각형 수는 그대로였습니다. 원본이 AI 생성 메시라 정점이 1,100여 개 조각으로 쪼개져 있어 단순화가 걸리지 않았는데, `weld`를 선행시켜 실루엣을 지킨 채(오차 = 메시 반경의 0.1%) 94%를 줄였습니다. 검증은 월드 bbox 비교가 맡습니다 — 충돌 박스가 이 크기에 맞춰져 있어 여기가 틀어지면 안 됩니다.
- **라이브러리 기본값을 의심했습니다.** drei `<Instances>`의 `frames` 기본값은 `Infinity`라, 배치가 전혀 변하지 않는 정적 경관도 매 프레임 인스턴스 전량의 행렬을 재합성하고 버퍼를 통째로 업로드하고 있었습니다.
- **그림자는 캐스터가 실제로 움직일 때만 다시 그립니다.** 이 월드에서 움직이는 그림자 캐스터는 플레이어와 태양뿐입니다. 제자리 이모트처럼 위치가 그대로인 변화까지 잡기 위해 별도 신호를 둡니다.

### 2. 신뢰할 수 없는 입력을 전제로 한 멀티플레이어

Realtime broadcast는 클라이언트가 보내는 값이라 위조할 수 있습니다.

- 방명록은 broadcast를 **"새 글이 있다"는 신호로만** 쓰고, 내용은 항상 RLS가 걸린 데이터베이스에서 다시 읽습니다.
- 수신한 위치·닉네임·애니메이션은 길이, 숫자 범위, 허용된 식별자 목록으로 정제한 뒤 사용합니다.
- 익명 사용자는 자기 프로필과 자기 흔적만 변경할 수 있고, 삭제는 소프트 삭제만 허용합니다. 범용 지형 편집 권한은 열지 않았습니다.
- 타입 검사와 빌드는 RLS·grant 문제를 잡지 못합니다. `pnpm world:verify`가 **앱과 동일한 요청 경로로** 권한 경계를 직접 찔러 확인합니다.

### 3. 리렌더 없는 실시간 동기화

접속자가 늘어도 React 트리가 흔들리지 않도록, 위치 데이터는 상태가 아니라 `ref`에 담고 `useFrame` 안에서 직접 보간합니다. 위치 브로드캐스트는 10fps로 스로틀하고 임계값 이상 변화가 있을 때만 전송합니다.

### 4. 데이터에서 파생되는 월드

월드 배치는 `src/constants/world`가 단일 원천이고, 충돌·미니맵·경계는 전부 여기서 파생됩니다. JSX에 좌표를 중복해 적지 않습니다.

- **충돌은 공간 해시 그리드**로 판정합니다. A\* 길찾기가 클릭 한 번에 수만 번 호출하므로 도형 전수 순회는 프레임 히치를 만듭니다.
- **월드 크기를 콘텐츠에 맞췄습니다.** 걷기 한계가 정사각형이라 콘텐츠가 없는 북쪽에 57유닛짜리 빈 잔디가 남아 있었습니다. 경계를 배치 데이터에서 파생시켜 걷기 면적을 48% 줄였고, 네 존 전체와 모든 상호작용 오브젝트가 여전히 도달 가능함을 스크립트로 확인했습니다.
- **경계 숲은 결정적으로 생성합니다.** 난수로 뿌리면 벽에 10~14유닛짜리 구멍이 생겨 월드 밖이 그대로 보입니다. 둘레를 균등 분할한 뒤 한 칸 폭만큼 흐트러뜨려, 줄 서 보이지 않으면서 최대 빈틈 4.2유닛(수관 반경 2.0~3.7)을 유지합니다.

## 로컬 실행

Node.js LTS와 pnpm이 필요합니다.

```bash
pnpm install
pnpm dev
```

[http://localhost:3000](http://localhost:3000)을 엽니다.

### 환경 변수

루트의 `.env.local`에 설정합니다.

```dotenv
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
```

publishable key를 사용합니다. **secret 또는 service-role key는 절대 넣지 않습니다.** Supabase Dashboard에서 `Authentication → Sign In / Providers → Anonymous Sign-Ins`도 활성화해야 합니다.

익명 로그인은 계정을 요구하지 않는 대신, 브라우저 데이터를 지우거나 다른 기기를 쓰면 기존 정체성을 복구할 수 없습니다.

## 검증

```bash
pnpm exec tsc --noEmit
pnpm lint
pnpm build
pnpm player:validate     # 플레이어 GLB 본 계층·클립 검증
pnpm scenery:validate    # 경관 GLB 디코드·간소화 비율·월드 bbox 검증
pnpm world:verify        # Supabase 권한 경계 (실행 시마다 익명 사용자 1명 생성)
```

## 에셋 파이프라인

3D 에셋은 원본이 `assets/`에 있고, 스크립트가 `public/models`로 런타임 버전을 굽습니다. 수동으로 교체한 결과물만 커밋하지 않고 생성·검증 스크립트를 함께 유지합니다.

```bash
pnpm player:rebuild      # 플레이어 GLB 재생성 (본 체인·클립 재작성)
pnpm scenery:optimize    # 경관 GLB 재압축 (meshopt 양자화 · webp 1024 · simplify)
```

`scenery:optimize`는 오차 0.001로 지오메트리를 간소화하고 텍스처를 1024 webp로 굽습니다. 등각 카메라가 20~40 유닛 떨어져 있어 2048 텍스처는 화면에서 구분되지 않으면서 VRAM만 씁니다.
