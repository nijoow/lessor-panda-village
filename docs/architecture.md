# 유지할 결정

- 모든 방문자가 같은 월드를 사용한다. 닉네임만 받고 내부적으로 익명 인증하며, 3~4명은 예상 접속 규모다.
- 인증 실패에도 로컬 산책은 가능하다. 쪽지는 캐시나 공개 스냅샷으로 읽으며, 캐시 없이 DB까지 중단되면 목록은 제공할 수 없다. 인터넷 없는 최초 실행은 지원하지 않는다.
- 계정·프로필 삭제 시 쪽지의 작성자 참조만 비운다. 본문과 작성 당시 이름·색상은 보존한다.
- 자기 프로필·쪽지만 변경할 수 있도록 RLS와 컬럼 권한을 적용한다. 작성은 5초 간격이며 재시도는 요청 ID와 본문을 함께 확인한다. 공개 조회는 활성 쪽지의 표시 정보만 반환한다.
- 죽순은 로컬 체험 상태다. 새로고침하면 초기화되며 도배 방지 수단이 아니다.
- 배치는 `src/constants/world`, 에셋 원본은 `assets`, 변환·검증은 `scripts`에서 관리한다. 적용된 DB 마이그레이션은 후속 파일로 변경한다.
- 기존 유리 패널과 Jua 글꼴을 유지한다. 자동 그래픽 품질은 낮음부터 시작하며 수동 선택도 제공한다.

## 남은 확인

- Quadro P400 2GB에서 1080p·30fps, 낮밤·대숲·여러 캐릭터 조건과 실제 내부 해상도 측정.
- 실서버 3~4인 접속·재연결, 실기기 한글 입력·가상 키보드, 다양한 시점의 캐릭터·벤치 간섭 확인.

로컬 SQL·모의 브라우저 검증은 실제 서버나 목표 장비 검증을 대신하지 않는다. `pnpm test:world-db`는 격리된 DB 검사이고, 계정과 데이터를 만드는 `world:verify`는 별도 테스트 환경에서만 실행한다.
